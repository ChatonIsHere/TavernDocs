# IDontSplit

An **interface** in `Root.Township`, the global namespace.

Empty marker interface. Components such as `ModifiableStaticObject` and `RotateOverTime` carry it, probably so build-time static splitting leaves their objects whole. Nothing in the server code checks for it.
