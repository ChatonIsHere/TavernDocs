# FlyCamInput.IPlayingActions

An **interface** in `Root.Township`, the global namespace.

Callbacks for the fly camera's "Playing" input action map (generated by Unity's Input System). Pass an implementation to `SetCallbacks`. Nothing in the game code implements it.

- **Listed in** [Global namespace: E to H](/mod/game-api/types/global-e-h)
- **Nested in** [`FlyCamInput`](/mod/game-api/types/global-e-h/flycaminput)
