# BuildTestAttribute

A **class** in `Alta.Attributes`, the global namespace.

Marks a method as a build test. Nothing in the server build looks for it, so it's probably read by an editor build check.

- **Listed in** [Other Alta assemblies](/mod/game-api/types/assembly-other)
- **Inherits or implements** `Attribute`
- **Attributes** `Usage`
