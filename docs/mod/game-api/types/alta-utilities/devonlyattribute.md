# DevOnlyAttribute

A **class** in `Root.Township`, `Alta.Utilities`.

Marks a settings property as developer only, for example `ServerSettings.IsAutoSaving`. Console commands use a separate `Alta.Console.DevOnlyAttribute`.

- **Listed in** [Utilities and other Alta namespaces](/mod/game-api/types/alta-utilities)
- **Inherits or implements** `Attribute`
