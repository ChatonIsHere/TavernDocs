# AllowNullAttribute

A **class** in `Root.Township`, `Alta.Console`.

Put on a command parameter (or a type converter) to let the parameter's converted value be null. Without it a null value fails parsing with `value was null`.

- **Listed in** [Console, logging and analytics](/mod/game-api/types/alta-console)
- **Inherits or implements** `Attribute`
- **Attributes** `Usage`
