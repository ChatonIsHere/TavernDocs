# Type browser

Every type in `TavernLib.dll`, one list per namespace, and a page per type with every member's signature, what it inherits, and where it's used. They're made from the assembly itself, so they include internal and private members: those are marked, and a mod reaches them through Harmony's `AccessTools`.

The guide pages in this section explain what to use and how. Start there; come here to look a member up. Game types in the signatures link to the [Game API type browser](../../game-api/types/overview.md).
