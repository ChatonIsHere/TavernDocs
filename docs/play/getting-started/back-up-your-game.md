# Back up your game

The game can't be downloaded any more. If something goes wrong, your backup is the only way to get it back. So make one before you change anything.

You only need to do this once.

1. Open your game folder (usually `C:\Games\Alta\A Township Tale`).
2. Click inside the folder and press **Ctrl+A** to select everything.
3. Right-click one of the selected files and pick **Send to**, then **Compressed (zipped) folder**. On Windows 11 you might need **Show more options** first, or pick **Compress to ZIP file**.
4. Wait. The game is a few GB, so this takes a few minutes.
5. Rename the zip to something like `A Township Tale backup.zip`.
6. Move it somewhere safe: another drive, a USB stick, or cloud storage.

Don't use the backup to play. Leave it untouched, so it's always a clean copy.

:::tip

Want to host a server later? It needs its own copy of the game, and this backup is where it comes from.

:::
