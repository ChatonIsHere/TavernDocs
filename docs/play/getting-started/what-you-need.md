## A Windows PC

The launcher works on **Windows 10 or 11**. It doesn't work on Mac or Linux.

## A VR headset

Any of these work:

- **A headset that works with SteamVR**, like a Valve Index, HTC Vive or Windows Mixed Reality headset. You'll need [SteamVR](https://store.steampowered.com/app/250820/SteamVR/) installed.
- **A Meta Quest or Rift on your PC**, with the [Meta Quest Link app](https://www.meta.com/help/quest/articles/headsets-and-accessories/oculus-rift-s/install-app-for-link/) (it used to be called the Oculus app). A Quest connects with a Link cable or Air Link.

## The game files

You need your own copy of **A Township Tale**, from when the game was still around. The game can't be downloaded any more, and we can't give it to you.

To check you have it:

1. Open File Explorer.
2. Go to `C:\Games\Alta\A Township Tale`. That's where the Alta launcher put it.
3. Look for **A Township Tale.exe** in that folder.

If it's there, you're set. If you put the game somewhere else, find that folder instead.

The last version of the game is `main-1.7.2.1.42203`. If you played until the end, that's the one you have.

:::tip[Lost your copy?]

Ask the community on [Discord](https://discord.gg/jNQUUDAYSj). Please don't ask staff. We can't help with getting the game's files.

:::
