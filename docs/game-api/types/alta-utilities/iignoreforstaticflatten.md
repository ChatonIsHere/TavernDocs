# IIgnoreForStaticFlatten

An **interface** in `Root.Township`, `Alta.Utilities`.

Marker for components that must stay on their own object when static scenery is flattened. Extends `IDontSplit`; used by things like `ModifiableStaticObject` and `RotateOverTime`.
