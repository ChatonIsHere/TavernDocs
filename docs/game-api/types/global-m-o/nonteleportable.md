# NonTeleportable

A **class** in `Root.Township`, no namespace.

Marker component: the teleport pointer won't land on a collider that has it. It is also skipped by static collider flattening.

- **Listed in** [No namespace: M to O](/game-api/types/global-m-o)
- **Inherits or implements** `MonoBehaviour`, [`IIgnoreColliderFlattening`](/game-api/types/global-i-l/iignorecolliderflattening), [`IDontSplit`](/game-api/types/global-i-l/idontsplit)
