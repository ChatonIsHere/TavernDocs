# LowLevelApiClient

A **class** in `Alta.Api.Client`, `Alta.Api.Client.LowLevel`.

The HTTP layer under `IHighLevelApiClient`: one method per endpoint of Alta's web API, which no longer answers. Most methods first refresh the login if needed (throwing `AuthorizationException` with none), and failed responses throw `ApiErrorException`, `ForbiddenException` or `HttpException`.

- **Listed in** [Alta.Api.Client](/game-api/types/assembly-api-client)
